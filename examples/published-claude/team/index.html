같은 입력을 또 읽을 때,
비용은 어떻게 달라질까?

프롬프트 캐시는 같은 입력 앞부분(prefix)을 반복해서 처리하는 비용을 줄여 줍니다. 출력 생성 비용은 줄어들지 않습니다. 일반 입력, 캐시 읽기, 캐시 쓰기, 출력 토큰이 각각 얼마를 차지하는지 직접 확인해 보세요.

입력 조건

프리셋

예상 총비용

총 비용 (USD)

—

구분토큰단가 ($/1M)비용 (USD)

    어떻게 계산하나요?

    • 전체 입력 = 일반 입력 + 캐시 읽기 + 캐시 쓰기. 캐시 토큰은 전체 입력에 포함된 부분집합이므로 두 번 더하지 않습니다.
    • 입력 비용 = (일반 입력 × 입력 단가 + 캐시 읽기 × 캐시 단가 + 캐시 쓰기 × 쓰기 단가) ÷ 1,000,000
    • 출력 비용 = 출력 토큰 × 출력 단가 ÷ 1,000,000. 캐시는 출력 생성 비용을 줄이지 않습니다.
    • 캐시 적중률 = 캐시 읽기 ÷ 전체 입력.

    적용 단가표

    모델일반 입력캐시 읽기캐시 쓰기출력

    단위: USD / 100만 토큰. 기준일 2026-09-07, API Standard 요금, 입력 272K(272,000) 토큰 이하 요청 범위입니다. 이를 초과하는 요청은 계산에서 거부됩니다. 도구 사용료, 세금, 구독 요금·크레딧은 포함하지 않습니다.
